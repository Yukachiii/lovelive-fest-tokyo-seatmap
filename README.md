# ラブライブ！フェス 東京ドーム 座席ファインダー

「LoveLive! Series 15th Anniversary ラブライブ！フェス Encore in TOKYO DOME」（2027年2月13日・14日、東京ドーム）の**スタンド席**の位置を、チケットの表記から図で確かめられる非公式ツールです。ナゴヤ公演版（[lovelive-fest-2-seatmap](https://github.com/Yukachiii/lovelive-fest-2-seatmap)）を東京ドーム用に作り替えたものです。

## できること

- 1塁側／3塁側／アリーナと、1階／バルコニー／2階を選び、列と番号（任意で通路・ゲート）を入力すると、ドーム図の上にピンで席の位置を表示します。チケットの表記（例：`21ゲート　1階1塁側　17通路　30列　170番`）を貼り付けて読み取ることもできます。ゲート番号から階や塁側を補います。
- アリーナではアップグレードS／A／なしを選ぶと、その区画を図でハイライトします。
- ステージまでの距離の目安、ステージに対する向き、双眼鏡の倍率の目安を出します。
- 東京ドーム公式の座席案内と、1階・バルコニー・2階の公式360°ビューへのリンクを載せています。
- 投稿文を作って、Xの投稿画面を投稿文入りで開けます。投稿文の最後にエリアページのリンクが入り、Xではそのエリアの「だいたいこの辺」画像がカードで表示されます。ゲート・通路・列・番号は、それぞれ投稿文から隠せます。
- 入力した座席は、サーバーに送られることも、どこかに保存されることもありません。最近調べた席の履歴だけは、その端末のブラウザの中に残ります（「履歴を消す」で消せます）。

## ステージ配置は仮です

東京ドーム公演のSTAGE MAPはまだ公開されていません（2026年11月16日時点）。今はナゴヤ公演の公式STAGE MAPと同じ配置（センター側のメインステージ、花道、センターステージ、アリーナ前方のS・Aエリア）と仮定して描いています。公式のマップが出たら、`index.html` の `STAGE`・`CENTER_STAGE`・`ZONES` と描画部分を直し、カード画像を作り直してください。

## 座席の推定について

番号から通路を出す式は、公開されている実際のチケット例（1階・バルコニー10件、2階8件）で合わせていて、どれも前後1通路以内に収まります。

| | 列 | 横通路 | 通路 | ゲート |
|---|---|---|---|---|
| 1階 | 1〜47 | 26列と27列の間 | 1〜48（1塁側ポール際が1） | 20〜24 |
| バルコニー | 1〜5 | — | 1階と同じ番号 | 30〜33 |
| 2階 | 1〜33 | 10列と11列の間 | 1〜14（1塁側が1〜6） | 40・41 |

## できないこと

- アリーナ席の細かい位置（ブロックや列の並びは公演ごとに決まるため、アップグレードの区画だけを表示します）
- 外野席
- 正確な座席位置の保証（位置・通路・距離は推定の目安です）

## エリアのカード画像（`og/` と `s/`）

`og/` は、1階の通路×前方・後方、バルコニーの通路、2階の通路×前方・後方、アリーナ3区画の、合わせて175枚のカード画像（1200×630）です。`s/` はそれぞれの画像をOGPに指定した小さなページです。図や文言を変えたときは作り直してください。

```
pip install playwright pillow
python3 tools/build_og.py --base https://yukachiii.github.io/lovelive-fest-tokyo-seatmap/
```

今入っている画像は、Google Fontsを読めない環境で `--offline` を付けて作ったため、文字がNoto Sans CJKになっています。サイトと同じZen Kaku Gothic Newにしたいときは、ネットにつながった環境で `--offline` なしで作り直してください。

## 公開（GitHub Pages）

リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main`・`/ (root)` にして保存すると公開されます。URLが変わった場合は `index.html` の `SITE` も合わせてください。
